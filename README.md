## 判断标准先立起来，再谈选哪家

挑VPS有三件事绕不过去：网络稳定性、价格、服务商规模。这三条听着像废话，但拆开看每一条都能筛掉一批商家。

**网络稳定性**不是看商家在页面上写“高速直连”，而是看它有没有说清楚去程和回程分别走什么线路。同样是洛杉矶或香港机房，走CN2 GIA、AS9929、CMIN2优化的，和走普通国际线路的，晚高峰是两回事：前者晚上八九点照样能用，后者可能直接卡成幻灯片。判断方法很简单，看商家敢不敢把“电信去程CN2、联通去程9929、移动去程CMIN2、三网回程优化”这种颗粒度写出来。只写“BGP”“三网直连”而没有具体线路名的，通常意味着回程没做优化。

**价格**要看两个口径：首期价和续费价。低价香港VPS里有一类常见操作是首月低价、续费恢复原价，而且只限新用户；有的新商家低价一波之后直接跑路。所以看到明显低于同行的价格，先确认三件事：续费同不同价、有没有退款保障、商家是不是自有资源。

**服务商规模**直接关系到你会不会半夜找不到人。小服务商没有自建机房，靠租二手服务器超售资源的案例不少，表现就是磁盘IO抖动、CPU被邻居抢、工单没人回。

还有一层常被忽略：**虚拟化架构**。KVM是全虚拟化，每台VPS是完整虚拟机、跑自己的内核、资源硬隔离，可以自由换内核、装Docker、跑WireGuard、搭K8s节点，甚至装Windows；OpenVZ是共享内核，一家超售全楼遭殃。现在还在卖OpenVZ的，基本可以直接跳过。丽萨主机这条线全系标的是KVM架构，这一点没有含糊。

## FAQ：几个被问得最多的问题

**KVM 和 OpenVZ 到底差在哪，值得为它多付钱吗？**

KVM是完整虚拟机，跑独立内核，资源硬隔离，邻居超售抢不走你的CPU时间片；可以换内核、装Docker、跑WireGuard、搭K8s。OpenVZ共享宿主内核，一家超售全楼遭殃，很多现代软件装不了。现在还把OpenVZ当卖点的商家，基本可以跳过。丽萨主机这条线全系KVM。

**CN2 GIA、CN2 GT、CMIN2、AS9929 分别是谁的线路？**

CN2 GIA和CN2 GT都是中国电信的承载网，GIA是质量最高也最贵的一档；AS9929是中国联通的精品网；CMIN2是中国移动的国际优化线路。所谓“三网优化”，就是电信走CN2、联通走9929、移动走CMIN2，三家各走各的优质路径。丽萨主机这条线是三网去程分别优化 + 三网回程优化，比只优化单一运营商覆盖面更全。

**原生IP和双ISP是一回事吗？**

不是。原生IP强调的是IP注册地与机房所在地一致、没有被频繁转手；双ISP强调的是IP在数据库里被识别为运营商属性（住宅感），风控友好度更高。做流媒体解锁看前者，做账号矩阵看后者。买之前先想清楚自己要解决哪个问题。

**年付一定比月付划算吗？**

账面上是。88元/月 × 12 = 1056元，年付566元，省46%。但年付版的硬盘只有10G、月流量600GB，如果你的用途需要20G以上空间，省下的490元会以“天天清磁盘”的形式还回去。先确认容量够，再谈省钱。

**香港和美国怎么选？**

看访客在哪。访客在中国大陆，香港的物理距离和回程优化是决定性优势，平均50ms左右是能做到的。访客在欧美，香港毫无意义，美国机房的大带宽便宜得多。两边都有，就分开买两台，别指望一台机器通吃。
